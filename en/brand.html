Brand guide

Original logo

The identity reference. The symbol (letter A and orbit) and both names must not change.

Derived versions

These are approximate redraws of the original and use a system font for text. A designer should refine them before final approval.

Colors

Navy #0B1F5CBlue #0A7CE8Cyan #19C3F5Mist #F2F7FD

Typography

System fonts only (Segoe UI, Tahoma, Noto Sans, Arial), with no bundled font files and so no extra licenses. Bold headings, 17px body.

Usage rules

  • Keep clear space equal to the height of the letter A.
  • Minimum symbol size is 24px.
  • Use the white version on dark backgrounds.
  • Do not stretch, recolor or add shadows.
